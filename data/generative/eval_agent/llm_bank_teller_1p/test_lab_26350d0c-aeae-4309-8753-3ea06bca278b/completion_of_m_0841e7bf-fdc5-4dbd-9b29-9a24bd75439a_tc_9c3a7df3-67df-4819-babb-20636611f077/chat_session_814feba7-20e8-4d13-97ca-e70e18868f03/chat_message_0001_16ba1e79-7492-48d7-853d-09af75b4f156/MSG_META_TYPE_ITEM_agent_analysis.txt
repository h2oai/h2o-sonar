Based on the web snippets provided, PEM (Privacy Enhanced Mail) is a widely used file format for storing and transmitting cryptographic data such as SSL/TLS certificates, private keys, and certificate chains. Although the original PEM standards from 1993 were never broadly adopted for email security (being supplanted by PGP and S/MIME), the textual encoding format they defined became very popular and was eventually formalized by the IETF in RFC 7468.

A PEM-formatted SSL/TLS certificate is characterized by its Base64 ASCII encoding, which makes it human-readable as opposed to binary formats like DER. PEM files typically begin and end with specific header and footer lines that identify the type of data contained within. For certificates, these markers are "-----BEGIN CERTIFICATE-----" and "-----END CERTIFICATE-----". The actual certificate data appears as Base64-encoded text between these markers.

According to the search results, a PEM file can contain various types of cryptographic data, including just a public certificate, a private key, or an entire certificate chain including public key, private key, and root certificates. PEM files can have various extensions such as .pem, .key, .cer, .cert, and others, though .pem is the most common. The PEM format is particularly popular for SSL/TLS certificates and is required by servers like Apache.

Several search results (particularly result_id: 4, 10, and 13) mention or provide examples of what PEM-formatted certificates look like. A typical PEM certificate starts with "-----BEGIN CERTIFICATE-----", followed by several lines of Base64-encoded data, and ends with "-----END CERTIFICATE-----". For creating PEM files, tools like OpenSSL are commonly used, with commands such as "openssl req" for generating new certificates or "cat" for combining existing certificate files into a chain.

It's worth noting that PEM is just one of several formats used for SSL/TLS certificates. Other formats include DER (a binary format), PKCS#7/P7B (for certificate chains without private keys), and PKCS#12/PFX/P12 (an encrypted container format for certificate chains with private keys). Converting between these formats is possible using OpenSSL commands, as mentioned in result_id: 18 and others.

## Historical Context

PEM (Privacy Enhanced Mail) is a widely used file format for storing and transmitting cryptographic data such as SSL/TLS certificates. Although the original PEM standards from 1993 were never broadly adopted for email security, the textual encoding format they defined became very popular and was eventually formalized by the IETF in RFC 7468. [en.wikipedia.org](https://en.wikipedia.org/wiki/Privacy-Enhanced_Mail)

The format is characterized by its Base64 ASCII encoding, which makes it human-readable as opposed to binary formats like DER. This makes PEM files easy to view and edit with standard text editors, and they can be safely transmitted via text-based channels like email.
