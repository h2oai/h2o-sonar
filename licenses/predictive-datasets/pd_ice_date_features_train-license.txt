Description:
This dataset is a 250-row subset derived from the Bank Marketing dataset
(bank_marketing_with_dates.csv), with the date column converted to integer YYYYMMDD format
for testing purposes.

The dataset inherits the CC BY 4.0 license from its source dataset.

Features:
- Date: Integer in YYYYMMDD format (e.g., 20080501 = May 1, 2008)
- Numeric features: age, balance, day_of_week, duration, campaign, pdays, previous
- Target: Binary (0/1)

Size: 250 instances, 9 columns

Replaces: pd_ice_weather_ymd_train.csv (which had BoM Copyright restrictions)
